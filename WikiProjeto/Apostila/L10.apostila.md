## Step 2: word_intro — λόγος
**Tipo:** Apresentação da palavra
**Narração:**
> "λόγος (lógos) — palavra / razão / discurso. No princípio era o Verbo, e o Verbo estava com Deus. A razão que ordena o cosmos."

**Exibição:**
```
"λόγος — Palavra"
```

**Grego:** λόγος
**Transliteração:** lógos
**Pronúncia:** LÓ-gos
**Significado:** Palavra / Razão / Discurso
**Etiologia:** Raiz *leg-, colher/ordenar; na filosofia grega, a razão que ordena o cosmos
**Contexto Bíblico:** João 1:1 — "No princípio era o Verbo (Λόγος), e o Verbo estava com Deus"

## Step 4: word_intro — ῥῆμα
**Tipo:** Apresentação da palavra
**Narração:**
> "ῥῆμα (rhēma) — palavra falada / declaração. A fé vem pelo ouvir, e o ouvir pela palavra de Deus. É a palavra como evento sonoro."

**Exibição:**
```
"ῥῆμα — Palavra Falada"
```

**Grego:** ῥῆμα
**Transliteração:** rhēma
**Pronúncia:** RÊ-ma
**Significado:** Palavra Falada / Declaração
**Etiologia:** De ῥέω, fluir; é a palavra como evento sonoro, o que foi dito em um momento específico
**Contexto Bíblico:** Romanos 10:17 — "A fé vem pelo ouvir, e o ouvir pela palavra (ῥήματος) de Deus"

**Exibição:**
```
"γράφω — Escrever"
```

**Transliteração:** gráphō
**Pronúncia:** GRÁ-fo
**Significado:** Escrever
**Etiologia:** Deu origem a "grafia", "gráfico", "gravura"; inicialmente significava riscar, desenhar

## Step 10: word_intro — ποιέω
**Tipo:** Apresentação da palavra
**Narração:**
> "ποιέω (poiéō) — fazer / criar / agir. Jesus fez este primeiro sinal em Caná. Deu origem a 'poema' (ποίημα): obra-prima."

**Exibição:**
```
"ποιέω — Fazer"
```

**Grego:** ποιέω
**Transliteração:** poiéō
**Pronúncia:** poi-É-o
**Significado:** Fazer / Criar / Agir
**Etiologia:** Deu origem ao inglês "poem" (ποίημα); o que é criado/feito. Efésios 2:10: ποίημα (obra-prima)
**Contexto Bíblico:** João 2:11 — "Jesus fez (ἐποίησεν) este primeiro sinal em Caná"
